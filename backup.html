Backup & Restore

Save everything you've entered on this website to one file, and put it back whenever you need to.

What's saved in this browser

Everything above lives in this browser only. If browser data is cleared, or you switch computers, it's gone unless you have a backup.

1. Download a backup

Includes the roster, schedule, news stories, legacy numbers, drills and video links, plays and playbooks, practice plans (with teams, warm-up groups and reminders) and scouting reports. It does not include the coach password.

2. Restore from a backup

  1. Choose a backup file you downloaded earlier.
  2. Check the summary of what's inside.
  3. Confirm to restore it. Items in the file replace the matching items here. Anything not in the file is left alone.

Tip: save the backup file somewhere safe, like OneDrive or email it to yourself. Make a fresh backup after big changes, such as a new roster or schedule.
