Coach Password

Make one password that works for the Play Designer and Practice Planner on every device.

  1. Type the password you want below.
  2. Copy the line that appears.
  3. Open js/data.js and replace the line coachHash: "", with it.

Only a scrambled (hashed) version goes into the file, not the password. Anyone who can read your site files could still try to guess it, so choose a long phrase. This protects against casual visitors, not determined attackers.
